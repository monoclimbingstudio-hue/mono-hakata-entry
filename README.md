# Mono Bouldering Competition IN HAKATA — ENTRY LIST（公開用）

博多店コンペのエントリーリスト公開ページ。Googleスプレッドシート（回答シート内「公開用」タブ）を
「ウェブに公開（CSV）」したURLを読み込み、エントリー名とカテゴリーだけを表示します。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（HTML / CSS / JS 一体） |
| `config.js` | **データ元のCSV公開URL**（大会が変わったらここだけ差し替え） |
| `mono-logo-white.png` | ヘッダーのロゴ |
| `vercel.json` | Vercel用の軽い設定（config.js のキャッシュ60秒） |

## データの流れ
```
Googleフォーム → 回答シート「フォームの回答 1」
                     └─ 「公開用」タブ（QUERYで エントリー名＋カテゴリー だけ抽出）
                          └─ ウェブに公開（CSV） → このページが60秒ごとに読み込み
```
- 回答シートの **J列「キャンセル」** に何か記入すると、その人は公開リストから消えます。
- フォーム送信 → ページ反映は Google の再公開間隔の関係で **最大5分程度** かかります。

## 別の大会で使うとき
1. その大会の回答シートに「公開用」タブを作り、A2 に
   `=IFERROR(QUERY('フォームの回答 1'!A2:J, "select D, B where B is not null and J is null order by A", 0), "")`
   （D=エントリー名、B=カテゴリー、J=キャンセル列。列が違う場合は文字を変える）
2. ファイル › 共有 › ウェブに公開 › 「公開用」+「カンマ区切り形式(.csv)」› 公開する
3. 表示されたURLを `config.js` の `csvUrl` に貼る
4. `index.html` の `<title>` と `<h1>` の大会名を書き換える
